# Zen

一款为专注写作与舒适阅读而设计的现代简约 Obsidian 主题。

[English](./README.md) · [简体中文](./README.zh-CN.md)

</div>

## 简介

Zen 去除不必要的视觉干扰，通过留白区分界面区域，并为 Obsidian 带来柔和的半透明视觉效果。主题细致调整了字体、间距、列表与导航，让阅读视图和编辑视图保持一致，同时针对中文内容进行了专门优化。

## 主要特性

- 简洁的界面、充足的留白与更少的分隔线
- macOS 半透明与背景模糊效果
- Windows 和 Linux 自定义背景图片
- 文件树、有序列表、无序列表与缩进参考线对齐
- 彩色标签页指示线与标题层级
- 为写作和阅读优化的字间距与行间距
- 实时预览与阅读视图尽可能保持一致
- 适配桌面端与移动端
- 内置 [Style Settings](https://github.com/mgmeyers/obsidian-style-settings) 插件配置项

## 使用要求

- Obsidian 1.9.0 或更高版本
- 建议安装 Style Settings 插件，以便调整主题外观

## 安装

### 社区主题

1. 在 Obsidian 中打开 **设置 → 外观**。
2. 在主题区域点击 **管理**。
3. 在社区主题中搜索 **Zen**。
4. 点击 **安装并使用**。

### 推荐字体

为了让列表序号、项目符号与缩进参考线更好地对齐，并改善中文阅读体验，建议安装 **霞鹜文楷等宽**：

- [下载 LXGWWenKaiMono-Regular.ttf](https://github.com/lxgw/LxgwWenKai/releases/download/v1.510/LXGWWenKaiMono-Regular.ttf)
- [查看霞鹜文楷字体家族](https://github.com/lxgw/LxgwWenKai)

![字体效果预览](./screenshots/font-image.png)

## 平台说明

### macOS

如需启用半透明背景效果，请在 Obsidian 中打开 **设置 → 外观 → 半透明窗口**。

### Windows 与 Linux

由于这些平台无法使用桌面壁纸半透明效果，Zen 通过背景图片实现相近的视觉氛围。如需更换背景图片：

1. 安装并启用 [Style Settings](https://github.com/mgmeyers/obsidian-style-settings) 插件。
2. 打开 **设置 → Style Settings → Zen → Windows/Linux**。
3. 在 **窗体背景图片** 中填写图片 URL。
